# CLAUDE.md テンプレート

Claude Code は CLAUDE.md を読み、AGENTS.md は読みません。AGENTS.md を使うリポジトリでは、直下に次の内容の `CLAUDE.md` を置きます（出典：https://code.claude.com/docs/en/memory 、2026-11-10 確認）。

```
@AGENTS.md

## Claude Code
- この節が AGENTS.md と食い違うときは、Claude Code ではこの節を優先する。
- [Claude Code だけに効かせたいルール。なければ、この節ごと消す。]
```
