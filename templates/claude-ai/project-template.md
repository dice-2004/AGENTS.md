# claude.ai プロジェクト テンプレート

claude.ai でプロジェクトを作るときの2つの入力欄の雛形です。`[ ]` をすべて埋め、不要な行は削ってから貼ります。

- 「何に取り組みますか？」（上限 8,000 字）：コーディネーターに目指してほしい成果。**何を・どこまで**と、スレッドの分け方を書く。
- 「プロジェクトの指示」（上限 16,000 字）：すべての新しいスレッドが読むルール。**どうやって**を書く。

字数の上限は、2026-11-09 に設定画面の表示で確かめた値です（公式ドキュメントでは未確認）。

個人設定（personal-instructions.md）にあるルールは重ねて書きません。違う挙動にしたいときだけ、その差分と「個人設定より優先する」旨を書きます（食い違うルールがあると、どちらに従うかが不定になるため）。

---

## 何に取り組みますか？

```
[このプロジェクトで何を達成するかを一、二文で。例: 〇〇の Web アプリを開発する。]

目指す成果：
1. [成果物と置き場所。例: GitHub の owner/repo への PR]
2. [あれば]

完成の条件：
- [何ができたら終わりか。例: CI が通り、レビュー指摘に対応した PR がマージされる]

進め方：[例: 依頼1件につき1スレッドで進める]
```

## プロジェクトの指示

```
# 置き場所
- [成果物・資料をどこに置くか。作業開始時に何を読むか]

# 進め方
- [例: 仕様書で合意してから実装する／たたき台を先に出して未決事項を質問する]
- [個人設定と違う挙動にしたいものがあれば、差分と「個人設定より優先する」旨]

# 書き方・品質
- [このプロジェクト固有の品質ルール。例: 使う Linter、テストのコマンド]

# 確認が必要な操作
- [個人設定の確認対象に加えて、このプロジェクトで確認が必要なもの]
```
